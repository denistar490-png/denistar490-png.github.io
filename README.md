# Denis Marino — Quantitative Finance & Data Science

Professional portfolio featuring research in neural SDE calibration, stochastic volatility and statistical learning, together with education and career highlights.

This is a static website for GitHub Pages. It requires no package installation or build step. The `.nojekyll` file preserves the static asset structure.

## Website files

- `index.html`: biography, education, experience, skills and contact details.
- `styles.css`: responsive design and locally hosted fonts.
- `app.js`: project case studies, maturity comparison chart and navigation.
- `assets/thesis-data.js`: 203 reference observations from the thesis repository.
- `assets/`: original CV, original project plots, fonts and surface artwork.

## Research repositories

- [Neural SDE Calibration for Volatility Surface Modelling](https://github.com/denistar490-png/Neural-SDE-Calibration-for-Volatility-Surface-Modelling)
- [Heston calibration to S&P 500 options](https://github.com/denistar490-png/heston-spx-options-calibration)
- [S&P 500 market-direction classification](https://github.com/denistar490-png/sp500-market-direction-ml)

The thesis visualisations use the supplied Heston target and neural model results. The Heston card's simplified smile is labelled illustrative; original figures appear in the case study. Academic results describe the supplied studies rather than live market performance.
